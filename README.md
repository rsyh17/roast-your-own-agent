A one-line roast of my own agent: forty tools, a perfect memory, and it still asks for clarification instead of just sending the email. The program writes that single line to `entry.txt` — tight, specific, and earned by watching it work. No setup, no explanation: the line stands alone, exactly as the judge reads it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
